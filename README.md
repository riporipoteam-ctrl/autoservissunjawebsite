# Auto Servis Šunja

Responsive one-page website for Auto Servis Šunja in Goražde.

## Files

- `index.html` — complete static website (HTML, CSS, and small progressive-enhancement script)
- `CNAME` — intended custom domain: `autosunja.sitey.my`
- `.nojekyll` — disables Jekyll processing

## Publish with GitHub Pages

The website source is committed on `main`. To make it publicly serve from this repository:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. In **Custom domain**, enter `autosunja.sitey.my` and save.
5. Wait for GitHub to validate the domain and issue HTTPS, then enable **Enforce HTTPS** when it is available.

A `CNAME` file alone does not enable GitHub Pages or attach a custom domain in repository settings.
